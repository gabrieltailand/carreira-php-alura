# Estrutura de um Array

Temos arrays normais:
* arrays numéricos
* arrays associativos

Ponde podemos definir as chaves e essas chaves precisam ser ou um número inteiro que definimos ou uma string qualquer. Não pode ser float, não pode ser booleano, outro array, por exemplo, precisam ser ou inteiro ou uma string.

Um array do PHP por baixo dos panos usa uma estrutura de dados bem mais complexa. Outras linguagens de programação simplesmente separam um espaço contínuo da memória para ter os valores, mas em PHP os arrays possuem vários superpoderes.
